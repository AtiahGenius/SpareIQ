Daily Reminder

This is a front-end prototype running entirely in your browser: images and OCR text are processed on-device with Tesseract.js, and data lives in memory for this session only (nothing is saved to disk or the cloud). Chart.js powers the analytics and PapaParse handles CSV import. A production desktop build would pair this same interface with a local encrypted SQLite database, the real file system for Receipts/ folders, and the Google Drive API for backup.
